## 一、一轮的标准做法（对应 skill 步骤 0.5-9）

1. **前置门**（skill 0.5）：编译+全量测试通过 + **测试面恒积累**（计量口径：`go test ./... -v 2>&1 | grep -c '^--- PASS'`，相对上轮不减——守恒读义务的每轮形态）。任一不过=先修装置再评审。
2. **变异先行**（skill 1，手动形态——无机器）：对本轮增量**触碰的守卫/探针**跑删除/翻条件突变（改前 cp 备份，**禁 git checkout 还原**——R61/c89219c 两实证），跑全量测试；存活变异体=实测盲区坐标，写入空白子 prompt 火力段。
3. **定增量**：`git log --oneline <prev>..<head>` + `git diff --stat`——增量范围写进 prompt。
4. **外层空白子**（skill 2，单审核位）：§三模板+增量范围。零上下文；4-lens+singularity 一体；每个结论（含「干净」）须真实执行的实验背书。
5. **证伪耦合门**（skill 3——正本在 skill GATE 块，此处只引锚句）：每个 B/M **先落红探针才进修复循环**——三档=确定性（一跑即红）/统计（预注册 N+差分）/实验级（真 LLM/真环境，预算门，**用户启动**）；三档都落不出=PLAUSIBLE 文档化（记边界，不修、不重置连胜）。锚：`三档=确定性/统计/实验级挂起；挂起→授权→差分判读；三档都定义不出=PLAUSIBLE 文档化`。
6. **清偿+同族穷举**（skill 4/5）：B/M 按根因全代码族搜索后一起修（不只修被报实例）；**族复发 ≥2 → 停止打补丁，升级 singularity 换结构**；每修必配**永久探针**（删修复即红——守恒律，覆盖不可失）；**minor 只积累不修**（台账清单轮转；修 minor 需用户逐次指令）。清偿证明=**当轮 `go test ./... -race` 绿**（105 号流程纪律——不建机器）。
7. **内环**（skill 6，战役加严形态）：清偿落盘后、提交前，对**清偿 diff** 再派空白子 4-lens+singularity——修复自带新缝（30% 律）当轮抓；有 B/M→修→再派（内环打转）；**0B/0M 才跳出**，外环收口。内环发现不计外环连胜；内环 minor 同律只积累。**记账段写完→跑一次全量测试**（流程形态，替代已退役的审计器）。
8. **守恒对账**（skill 5 RECON 读义务，grep 形态——无机器）：收尾对台账已钉家族 grep 其探针名仍在测试文件（名册−清单=覆盖缺失红；清单−名册=登记义务告警）；退役探针须台账显式登记+证据。
9. **收轮（条款双源）**：空白子报告尾部提议 1-3 条下轮火力面条款；修复者裁决（采纳→attack-corpus §二/本文件 §四；驳回→记录理由）。提案者≠下轮空白子。
10. **记账+提交**：台账 `## R<N> 复审记账`；本地提交。**推送 MR 须用户口令（逐次授权）。**

## 二、停机与定级（skill 9 + 严重度矩阵——正本在 skill）

- **停机**：外层连续 **2 次 0B/0M**；**叠加守卫**：退出前最后一轮必须全强度外环；止损线（skill 校准值 8 轮/15M token——本战役已用 66+ 轮，按用户裁定续/停）。
- **严重度×可达性**：B/M 且 git 可跟踪/本地构造→修复循环；**趋零可达→文档化通道**（记边界，不进修复循环、不重置连胜）。
- **漂移类定级**：审查对象为方法论/技能文档时，复述漂移类（措辞分叉/声明-实态差/指针缺口）**最高 MINOR**——文档化+结构治理通道，不重置连胜；引擎可执行面（prompt/脚本/校验器行为）漂移按实害定级。
- **结构转移后义务**（skill 7）：换结构后强制一轮全强度外环+证伪器再生（旧探针新结构重跑，退役须登记证据）。
- **minor 只积累不修**（用户 2026-11-06 裁定）。

## 三、空白子 prompt 模板（引用填充，<RANGE> 为唯一样板插值）

```
你是独立评审者（零上下文空白子，第 <N> 轮）。对 git 仓库 <REPO> 的 Go 测试代码增量做
4-lens + singularity 审查。

审查对象：git -C <REPO> diff <RANGE>。先看提交链再逐文件读。

方法论两把枪：
1. 4-lens：简单性/一致性/支撑性/保真度（doc 与代码、声明与事实互相对得上吗；每个声明
   有可当场复跑的机械证据吗；测试测的是它声称测的东西吗）。
2. singularity：问题重定义（守卫/断言实际测的是不是更容易的问题）+ 可达错误状态（构造
   具体输入或源码编辑使被宣称拦住的东西静默通过）。每个可疑点动手验证，不许只凭读码定级。

火力面：读 <REPO>/agent-festival/docs/attack-corpus.md §二（判据×用例映射——逐条过）与
<REPO>/agent-festival/docs/fixture-guard-pattern.md（守卫形态模板）。已知盲区坐标（变异先行
产物，本轮增量的存活变异体）：<按需插入或「无」>。

严重度：B=守卫失效/假声明/病漏网；M=重大不一致或可证弱声明；m=措辞/风格/小漏。
趋零可达的发现走文档化通道（记边界不重置连胜）。方法论文档的复述漂移最高 MINOR。

基本卫生：gofmt / go vet / go test ./... -count=1 -race（<REPO>/agent-festival/go）。

输出：发现按 B/M/m 分级，附 文件:行号 + 你实际跑过的命令与输出；收尾 B/M/m 计数。
没有发现就明说。宁可错杀，不许客套——每个「没问题」都应是你验证过的。
突变实验做完还原（cp 备份形态，禁 git checkout），结束前 git status 被跟踪文件仅限原有改动。
报告尾部：提议 1-3 条下轮火力面条款（你发现本清单缺的检查）——修复者会裁决。
```
