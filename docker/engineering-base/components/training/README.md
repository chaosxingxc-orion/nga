# Registered training component

`dispatcher.py --config CONFIG --output OUTPUT` calls the registered `k1-full-train-v1` component. Its only supported full recipe is Qwen3.5 0.8B, two epochs, 3,116 steps and 186 LoRA pairs. It validates the complete model inventory, dataset content, installed source pins and configuration, and requires a private, caller-created absolute output directory. It binds owner, output, config excluding the checkpoint pointer, model, dataset, recipe, seed, component and trainer sources to checkpoint identity. Resume requires an explicitly supplied path and digest in the owned `ckpt` directory; it never discovers a checkpoint automatically. AdamW, OneCycleLR and trainable tensors are saved together via a file handle, flush, fsync, rename and directory fsync. An incomplete checkpoint blocks resume. The caller must ensure exclusive ownership and immutable input mounts; hashes are integrity bindings, not signatures against an adversary with write access.

Each invocation that reaches training creates an `attempts/<id>` lifecycle record with a heartbeat and terminal exit code. The external launcher must provide a lease, durable stdout/stderr, a relaunch command and a marker for failures before training begins. The trainer itself writes step progress and per-chip throughput. The component does not launch containers or grant accelerator ownership.

`qualification.py` is a CPU linear fixture, **not LoRA qualification**. It checks two-step AdamW and OneCycleLR checkpoint/restore behavior and labels results accordingly. It is not a result for the 3,116-step recipe. The 2B, 4B and 9B recipes are not registered here: their pair counts and other parameters must be derived and bound from their exact retained plans before implementing those dispatches. Do not reuse 186 by assumption.

The enclosing image must install this directory, integrate the registered dispatcher and closed schema, and pin its contents. The current shared Dockerfile/adapter are not modified by this component and currently dispatch an older unprotected training path. See the repair handoff before integration.
