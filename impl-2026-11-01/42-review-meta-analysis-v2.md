## 三、第一性原理：文本可伪造，执行不可伪造

10 轮 20M 最底层共有一个物性：**它们都是文本**（doc 措辞、台账条目、钉的子串、判据行、清单）。
文本的共同失效模式是「说与做可以分叉」。不可伪造的是**执行**：隔离副本上真跑 `go test` 看**退出码**。

**验证塔终止条件（回答 M6 的「谁给守卫的守卫做电池」）：**
> 塔不追求无限不可伪造；每层职责=使下一层伪造成本高于收益；
> **信任根=隔离副本上 go test 的退出码（观察，非文本）**；台账/判据/doc 一律是视图，不是证明。

## 四、Singularity 核心产出：C1' —— 换观测面，不是更好的钉

第七形的死穴是**所有文字钉/形态钉共有的**：钉形态，而形态是开放集。AST 钉只是更细的枚举网
（空白子 M4 判得对）。**结构性答案不是更好的钉，是换观测面：**

```go
// 件 3' 错误返回式守卫构造器（替代 tFatal 吞错式）
func canaryMaskingStreamGuarded(streams ...[]ledger.Event) ([]ledger.Event, error)

// 一对形式无关的行为探针（不看源码任何形态，只看输入输出关系）
if _, err := canaryMaskingStreamGuarded(drifted); err == nil { t.Fatal("guarded path accepted drift") }
if _, err := canaryMaskingStreamGuarded(healthyVariant); err != nil { t.Fatal("healthy rejected") }
```

**为什么杀全族（逐形验证）：**

| 突变形 | 构造器行为 | 探针 |
|---|---|---|
| M-A 掐调用 | drift→nil | 红 |
| M-B 体 no-op | drift→nil | 红 |
| RR1 `_ =` 形 | drift→nil | 红 |
| RR2 吞错 | drift→nil | 红 |
| BF if-false 埋葬 | drift→nil | 红 |
| **第七形 早退死代码** | drift→nil | **红** |
| 参数忽略 | drift 被丢、查健康→nil | 红 |
| 未来任意 re-shape | 只要在 drift 上返回 nil | **红** |

探针不枚举形态，只观测唯一语义量：**漂移过守卫路径是否产生 error**。枚举问题消失。
与 E6 `DispatchIfCurrent`（拒绝+控制事件）、R53 夹具自守卫同构——让声明的否定产生可观测值。

代价：~6 个调用点机械改签名；件 2 tFatal wrapper 降级为可选便利件
（它是整个连接层 saga 的结构成因：吞错式签名制造了「连接不可观测」这个温床）。

**C1' 自身新缝（M8 纪律，先声明）**：构造器内手写漂移检测绕开纯检查（check-复制形）——
由 meta 探针五形态表 + 源码钉（降级为诊断件）覆盖；手写件追不上五形态表的完备性是**声明边界**，
非结构性死亡。诚实终态：行为探针对 + 源码钉降诊断 + 边界声明。
