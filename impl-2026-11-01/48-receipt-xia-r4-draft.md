**纪律 1（无害吸收：注入件以控制事件入账、零副作用）——文法半可达，实验证明如下**：
- **证明了的**（E7a②）：对已采纳操作手工追加一条 **pin 全匹配**的 `[CANARY]` control 事件

  任意消费者。**控制事件类别在账本文法内可承载 canary——「无害吸收」的数据形态成立。**
- **反证明了的**（E7a①③）：①生产 API 直注入 unknown-op：纯返回值拒绝、**零控制事件**

  的 control 事件：**Open 整体拒绝**（EVENT_BEFORE_ADOPTION 对 control 同样生效）。
  **合起来：canary 的生产注入路径当前文法不可达**——「写入 API 缺失」从直觉变为实验锚。
- **洞形锁定**：E7a② 负孪生——pin 单字段错配（Model 漂移）即被拒。洞的形状恰为「pin 匹配」，
  无更宽通道。
