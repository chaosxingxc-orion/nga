# provider-v3 runtime

Exact six-file runtime from engineering-resource-strict-json-astra-20261105-v3/verification.
The review handoff is ACCEPT_SCOPED_SIMULATION_ONLY; it does not qualify physical deployment
or compatibility with newer trained hosts. inventory.json records SHA-256 for every runtime file.
The wrapper independently pins the same bytes; inventory is not an authority for executable code.
Rebuild with tools/build_resource_provider_v3.py and the review's PINS.json and verification root.
