## 2. 本阶段交付及统计规则

交付为“参考模型 × 数据集及版本 × 分区 × 计算方法”的指标表，包含数据覆盖和明确缺失项。首先统计现有本地镜像中可追溯的公开测试结果；需要新推理的单元单独列出，不能用文献其他分区或其他模型的数字补齐。

每个数值记录：模型／checkpoint／训练阶段、数据集／版本／split、样本数及统计单位、指标名与公式、聚合权重、readout／温度／tie 处理、原始路径及哈希、是否本地重新推理、是否具有可比性。

- **test 与 dev 分开。** 只有 dev 的模型在 test 表标为“未报告”，不把斜线前面的数搬到 test。
- **原生指标并列。** question micro accuracy、dataset／state macro accuracy、record exact match、chance-corrected index、Macro-F1、Brier／ECE 的不同定义分别列，不平均成一个总分。
- **同名指标也核对定义。** 尤其 Brier 是否二元或多类求和、是否软标签，ECE 的分箱和置信度对象，以及 NOTA、permuted 是否纳入 headline。
- **不同来源冲突保留。** README 与 release／summary 的数值冲突先注明来源和版本；没有证据时不强行归因成不同公式。
- **不同测试集不排统一名次。** 指标只在相同数据、分区和方法内可直接比较；不同 public source 的子集也不能只看名称就合并。
- **缺失不是零。** 未发布、只有 dev、无官方 split、原始记录缺失、原生模型不可得分别编码。

用户 D1 已授权本阶段参考模型 test 指标的统计和必要参考评测，无需再次询问是否可以查看这些参考 test 结果。它不等于批准读取尚未完成选择的 NGA 训练候选 test，也不取消 K0 的来源／数值前置验证。

本阶段先固定参考模型与评测口径，再读取或重算参考结果；不以测试结果反复调参考模型的温度、prompt 或权重。参考测试证据会影响后续训练设计，未来在这些公开 test 上的比较必须披露这一开发暴露，不能把已经用于设计的分区重新称为完全未见的独立验证。

## 3. 与业务目标的关系

真实业务暂缓不意味着目标只剩 accuracy。当前依据既有研究目标，分别整理：

| 目标 | 现有公开证据可观察什么 | 尚不能推出什么 |
| --- | --- | --- |
| 正确判断 | accuracy、Macro-F1、case exact、跨来源结果及退化对照 | 实际业务错误代价下的净收益 |
| 定义遵循与可配置 | 规则迁移、定义交换、留出规则族／数据源 | 非技术业务作者已能有效配置，或 G2／G3 已通过 |
| 决策稳定 | 配对 flip、置换／扰动、反事实 discrimination | 总体 accuracy 高就等于一致；现成数字替代 G1 分母 |
| 可信概率与拒绝 | Brier、分版本 ECE、selective accuracy／coverage、NOTA | 任意业务分布上的校准或可安全自动执行 |
| 推理成本 | 原文延迟／吞吐／硬件、必要本地同口径测量 | H100 与 Ascend 耗时直接可比 |

这张表是本项目的目标映射，不是新增文献结论。新的测量若需要修改样本、阈值或协议，仍在运行前登记 defect registry、无约束最优解及 discrimination counterpart。

## 4. 当前顺序

1. 查清两套本地模型／数据镜像，列完整参考模型与分区清单。
2. 提取已发布 test 的总体、按数据源和按方法指标，保留来源及哈希；复核关键数字及冲突。
3. 对没有 test 或缺少指定方法的单元列缺口；原始逐项预测足够时按明确公式重算，标记为重算而非文献原值。需要新推理时另写评测记录并冻结原生配置，不启动训练。
4. 汇报统计结果、可比较范围和与本项目目标的距离；届时才讨论训练目标、数据、loss、readout、消融和 seed 设计。

既有运行和修复不会被冒称为本阶段参考结果。本报告不终止已经启动的工程验证容器，也不将取消算力预算解读为改变其他项目资源所有权。
