## 1. 目标和范围

在 175（`npu`，8 张 Ascend 910B3）上，复用现有镜像、本地数据和训练实现，完成
Qwen3.5 0.8B、2B、4B、9B 的基线、训练和优化。形成可复核的同测试集比较，并分别报告
准确率、语义稳定性、训练效率和推理成本。每个规模先解决工程效率问题，再开展完整训练。

当前重点是模型研究项目；S1+S2 agent 循环和企业工作台属于整体架构的另外两个项目，
不纳入这批训练交付。27B/35B、RL、K3 一致性定向训练和 K4 全参数训练暂不进入本批规模化任务。

- 主评测：`decision-v7` dev 1,264 / test 1,200；`transfer-v4` dev 656 / test 656。
  两套 headline 仅包含 clean questions；permuted/NOTA 单独报告。
- 稳定性诊断：T1 名称变化、T2 定义交换/重排、T3 问题集合变化；覆盖 typed-decisions、
  akhilaaa3、Open-Jev synthetic 的适用任务。遵守已登记的无效 cell、冲突样本及小样本限制。
- 0.8B、4B、9B：各形成“两套数据 × 未训练基座 / NGA LoRA / 官方 Kev checkpoint”的比较表。
  核对 checkpoint revision 与训练阶段；不把同参数量直接当作同一基座。
- 2B：形成自有模型规模阶梯，不虚构不存在的 Kev-2B 官方参考。
- 每个尺寸先有 K0；constant、uniform、empty-input、question-only 对照随结果一起提供。
- 后续按来源展开分项表，不能用总体 micro accuracy 代替跨来源或业务规则泛化结论。

开发集用于诊断、选配方和效率验证；最终 test 保持封存。官方模型 test 复现也放在统一最终读取阶段，
不能提前看自己的 test 结果再调参。所有数据、转换器、基座和代码记录版本及内容哈希。

## 6. 训练效率优先规则

复用 `nga-verl-qwen35-v030:20261029`；当前主训练入口为单卡 PyTorch/PEFT `r3_code/train_r3.py`，
不是旧版 verl/FSDP 训练路径。工作代码在 CephFS，Git 中 `experiments/r3_sft/` 为快照。

1. 每个正式批次前做有界、代表性的性能测量，至少 warm-up 后10 steps且60秒；
   若存在长序列或后期 allocator 压力，要延长到足以覆盖该风险的窗口。
2. 同时记录 questions/s/chip、tokens/s/chip、芯片数、allocated/reserved GiB、step分布和有效训练工作量。
   K1/K2 计算量不同，不能仅用 tokens/s 排名。
3. 按 profiler 处理瓶颈：任务队列、长度分桶/补齐、microbatch、checkpointing、K2 prompt共享、
   allocator；已有 `TASK_QUEUE_ENABLE=2`、`expandable_segments:True` 优化保留并验证。
4. 速度优化必须通过损失/梯度与同配置复跑噪声对照。未获准入的 fast_ref/FLA 不能因为更快就替换正式内核。
5. 运行中持续监控；效率异常先诊断修复，停止扩展下一批。需要中止当前作业时先保存可恢复 checkpoint。
   不擅自更改已冻结的批次、并发或学习率语义。
6. 限定芯片依据分配文件及容器设备占用核验，不能把瞬时0%利用率当作空闲授权。

## 7. 指标与“对齐”的判定

- 主指标：两套 clean question micro accuracy；同时报告按来源分项、样本量、tie数和区间。
- 稳定性：T1/T3 argmax flip、T2 discrimination、NOTA both-sides-right；弃权率与 operator accuracy 单独报告。
- 成本：训练总芯片小时、吞吐、峰值显存、推理延迟/吞吐；只在同硬件、同批次、同长度与缓存口径下比较速度。
- 当前0.8B K-align最低线为 K1两seed平均 decision dev≥0.80、transfer dev≥0.60。
  它不等于“复现成功”；Kev stage-1参考区间及±1pp措辞规则按预注册执行。
- 用户要求是多组模型×数据对齐，现有§9.1只定义0.8B；在新规模结果读取前补齐可比矩阵、
  参考版本、训练阶段、区间和缺失参考处理，交 Astra 审核，不能事后选择有利 cell。
  上游已有 `experiments/q35-4b.json`、`q35-9b.json`（各 seeds 0/1，lr=5e-5）；
  对应 `runs/q35-4b/`、`runs/q35-9b/` 各两份 trial 结果也已定位；下一步核对分区、
  阶段与 provenance，不能沿用旧记忆而误判没有同基座参考。
- 官方 release经过额外训练阶段，NGA本轮为stage-1风格SFT；两者作为结果比较时披露差异，
  不称严格配方复现。未实现的原生typed-readout能力不作性能宣称。
