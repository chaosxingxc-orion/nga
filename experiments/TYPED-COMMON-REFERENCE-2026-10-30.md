# Typed Decisions common reference protocol

Pre-registered 2026-10-30 before any E26 model inference. First implementation: native Kev 0.8B/4B/9B; Open-Jev 2B/9B and initial Nimble remain intended subsequent adapters, not implicitly covered.

Defects 12/16: measure typed decisions with comparable original arithmetic and intact population. Constant or label-leaking output is a degenerate optimum; label-only edits must not change model input, candidate edits must change mapping, and wrong/missing/duplicate receipts must fail. Aggregate accuracy is not consistency or new training benefit.

Exact original test parquet SHA256 `4f294f218ea1da27f3efef936359389c62ea4d3973a41457732990f1d31b647c`: 400 ordered states, 2,000 decisions, four workflows. Decode state/questions exactly as original scorer; send all five questions, no gold/factors/ID metadata. Preserve question and candidate order. Native Kev pointer, fp32/eager, merged LoRA, published checkpoint temperature; additionally recompute T=1 from identical logits. No random sampling/seed, fitting, temperature selection, candidate clipping or input truncation.

Original formula panel uses `score_with_jobs.py` SHA256 `6854ef67b8cff64ebc71e5b47d0f44e78f92124fc0d62f539095cab5625844f8`: gold insertion order and unnormalized rounded gold; prediction probabilities normalized (zero/missing becomes uniform), first-index ties, soft Brier, KL floor1e-9, ECE10 `min(int(conf*10),9)`, 2,000 decision equal weighting. This is original **arithmetic on raw native readout**, not a claim of original HTTP/vLLM reproduction. Preserve raw wire answers separately: Kev noul wire lacks the probabilities field required by the original scorer, so do not silently report a wire-score reproduction.

Strict panel reports expected/returned/valid/invalid/unsupported/overlength/failed, accuracy denominator 2,000 with invalid wrong; probability metrics only valid questions and their denominator. Driver rejects invalid native distributions rather than publishing success. Candidate/logit order, finite probabilities, softmax consistency and typed identity are required. Score expected-value MAE is a separately named diagnostic, not substituted for original ordinal argmax accuracy. Raw and serving panels each retain overall/type/workflow cells and review flags.

Context fixed before length inspection: max_state8192,max_branch8192,max_packed16384, strict. Full 400-state token-only preflight for every tokenizer; any overlength blocks that model's formal inference, never removes the row. Synthetic five-question fixture validates native shape, repeat arithmetic and token order; full-data longest length is only an engineering admission measure. Actual NPU inference starts only after implementation/preflight review. 175 only, existing immutable image, retained detached containers, CephFS heartbeat/log/terminal and item receipts; exact guarded relaunch and locked resource claim required. Automatic acceptance requires full identities, dependencies, checkpoint temperature/base metadata independently read with weights_only=True, terminal/wrapper and actual retained Docker exit.

Status: implementation/preflight preparation. No E26 inference, complete metrics, Astra approval or training benefit yet.
