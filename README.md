## 摘要

本报告调研 **Jev 类（System One）单遍决策模型**与由它使能的**快/慢协同 Agent 框架**，目的是在我们自己训练这类模型之前，先把问题理解清楚：哪些工作解决了哪一类问题，哪些是我们识别出来而现有工作没有覆盖的盲区。

证据基础是 **283 篇 arXiv 论文**（其中约 70 篇读了全文）、TypeSafe 官方文档 17 页、GitHub README 25 个、模型卡 6 个、博客与排行榜 14 页，时间窗口以 2026 年 9–10 月为主。**报告中的每个数字都回到缓存的原文核对过，核不到出处的一律删除。**

报告的组织轴经 2026-10-28 的讨论确定为"**语义理解的泛化**"，而不是最初的"业务成本"。六轮讨论的归纳锁定为**讨论稿**（§2.2：我们要做什么、业务目标、现有工作的支撑、缺陷登记表、最终框架），§2.3 与 §8.2 是对它的对抗性检视。**§2.2.5 的 P0″–P5″ 是本报告最终的框架表述。**

## 3. 核心结论

### 3.1 对象：它是什么，不是什么

1. **Jev 的价值在接口、成本、延迟与校准，而非准确率**。28 篇论文的早期审计结论是"类型化读出本身未显示出独立于同类标签概率读出的准确率优势"（[2609.32160](https://arxiv.org/abs/2609.32160)）；现成聊天模型直接读 logits 已是 Jev 式决策模型（[2610.02076](https://arxiv.org/abs/2610.02076)）。更锋利的表述不是"价值在接口契约"，而是**契约把决策的记账交给代码，把语义留在模型里**——把开放世界情形映射成带刻度的观测这一步没有任何代码写法（§2.1.7）。
2. **架构已被还原并被 15 个以上开源配方复现**：共享状态前缀 + 隔离的问题分支 + 列表式概率读出。0.6B–9B 的决策微调模型可用，**领域微调的小模型胜过通用的大模型**（SecJev-0.8B 比 Kev-9B 高 20.51 pp，[2610.03073](https://arxiv.org/abs/2610.03073)；AgentDecision-4B 在分布外任务 91.5% 对 Jev 82.0%，[2610.21412](https://arxiv.org/abs/2610.21412)）。
3. **骨干约束**：Qwen3.5 / 3.8 是 Gated DeltaNet + 注意力的混合架构，循环层不认注意力掩码，树形掩码无法隔离兄弟分支。现有做法是每问一行（Kev）或前缀分叉（推理快 8–19 倍，但穿过缓存的梯度尚未实现）。针对混合架构的"训练时分支隔离"文献**零命中**（§1.3）。
4. **同一个词在不同论文里是不同定义**："决策模型"按接口、契约或用途定义；"置信度"是四个不可合并的量；ECE 至少五种算法；"翻转率"五种分母；"RLCD"四种含义。跨论文数字不可直接比较的根源在此（§1.4.10 列出定义问题前必须取定的六个分歧点）。

### 3.2 语义：这是最弱的一层

5. **标签名压倒定义，而类型永远正确**。名字-定义对调使平均 AUC **93.8% → 23.2%**（低于随机），而**类型错误率全程 0%**——类型正确 ≠ 读了定义（[2609.26758](https://arxiv.org/abs/2609.26758)）；**删除全部定义准确率不变**（0.8487），而定义单独能撑起 0.7971，标签与定义矛盾时跌到 0.2281，原因定位在提示渲染（[2610.02586](https://arxiv.org/abs/2610.02586)）；1–12B 小模型少样本下**语义覆盖率恰好为零**（[2511.21038](https://arxiv.org/abs/2511.21038)）。**没有任何论文直接测量"决策微调是否保留/破坏 ICL"**（§3.1）。
6. **规则能被读出，但只在 22%–72% 的情况下被执行**（[2610.18579](https://arxiv.org/abs/2610.18579)）；含算术/时间的对照对从难度 1 到 3 准确率 87.7% → 57.4%；正确答案缺席时拒绝率只有 **7%**，加一个阈值可到 **79%**；兜底选项让 Intern 从 97.9% 跌到 23.1%（§4.1）。
7. **D3 已有可借鉴的原语雏形**（三原语、扇出、分类树、复合打分、置信路由；SemTree 的 Yes/No/Unknown 节点树；"概率感知、确定性裁决"的并集界），但**把自然语言业务规则编译为可验证逻辑的工作都面向生成式 LLM，尚无针对单遍决策模型的规则语言**；而规则制品必须**按裁判编译**（换裁判 67.70% → 47.87%，[2610.13999](https://arxiv.org/abs/2610.13999)）（§3.2）。

### 3.3 一致性：主指标，但分母未取定

8. **"一致率"在取定分母之前不是一个指标**。同一个模型：字节级重跑口径 **99.83%**，顺序置换 0.11%–8.30%，保答案对抗变体口径 **53.7%**（攻击翻掉正确决策的 46.3%，0.8 阈值下仍被执行的决策里 23.5% 是错的，[2609.31142](https://arxiv.org/abs/2609.31142)）——**两端相差 46 个百分点**。五个候选分母里，两个已达成或按构造可买到（故作为训练目标价值为零或很低），唯一有业务含义的"**业务声明的等价类**"**无人定义过**（§2.1.8、§7.5 第 13 行）。
9. **聚合准确率对我们关心的变化是盲的**：换 8 种选项顺序准确率变化 **<2 pp** 而累计失败集扩大 **27–29%**（[2610.35826](https://arxiv.org/abs/2610.35826)）；修正与回退相互抵消时准确率不变而决策已变（[2609.27678](https://arxiv.org/abs/2609.27678)）。而重复性本身已解决且**会误导**——重复的错误答案占观察到错误的大部分（§4.2.2）。
10. **D4 远不止四项**：报告枚举 **30 个子维度**（A 同输入稳定性 / B 选项表示依赖 / C 逻辑相干 / D 不确定性语义 / E 输入内容敏感 / F 接口与动作），每项给出可量化定义与现有证据；同一事实、同一规则，概率会随 **25 种与业务无关的因素**变化（§4.2）。

### 3.4 系统：成本是使能条件，不是目标

11. **被消除的是解码 + 往返 + 解析成本**：rubric 评审贵 16–357 倍、慢 5–350 倍；审核约 0.000025 美元/次、约 100 ms，AUROC 与 14 个前沿系统中 13 个不可分；本地 2B 30.9 ms 零输出 token 对前沿 API 8,758 ms。**可对业务承诺的只有两条**（输出必在选项集内、一次前向答完整个请求）；校准、等价提法不变性、兜底、unknown、自知、概率自洽、可审计、风险预算**八项都有独立审计测出的反例**（§5.1.2）。
12. **支撑 System1+System2 有五个工程上不同的位置**：前四格（入口闸、过程监控、证据/记忆面、慢模型输出读出器）有正面证据，**第五格"闭环执行者"普遍失败**。而"更快的决策 ≠ 更好的 Agent"：孤立问题最准的模型只解出 69.5% 的 Agent 任务；不拟合阈值就委托工具选择降 19.0 点；Jev 控制器让成本 +19% 而通过率不变（§5.1.4、§5.2.1）。
13. **命题自带一个梯度**：确定性往 harness 里推到底，模型就变成冗余（类型化策略字段上一条确定性规则全对；不带模型的控制器在 τ²-bench telecom 解出 **79%**）。所以可用区间的上界是业务字段的可结构化程度，下界是决策的重复度（§5.1.5）。

### 3.5 学习侧：该改的是形状，不是目标函数

14. **学习算法几乎没有"换算法"**：改的是读出位置、目标函数里加一个适当评分项、以及数据构成。可证实有效的是 LoRA、数据构成、结构隔离与温度；**单遍模型上强化学习为负或无效**（发布 RLCD 配方比交叉熵低 2.5–3.0 点；REINFORCE −10.2 F1；GRPO 无增益），正面证据都绑定推理链——但这条结论的证据基数只有三个异质数据点（§6.1、§8.1.4）。
15. **"SFT 无法带来一般意义上的泛化"：强形式不成立，弱形式成立**。同任务族的新样本/新来源上可靠迁移；但新 schema（27B 上 SFT 增益约为零）、新符号操作、先验偏移（同样的 SFT 在金融情感上 +10.0 或 −12.0）、校准迁移与推理深度四层**没有任何正面证据**。跨层移动结果的是基座规模、指令调优起点、监督分布与结构约束，**不是监督目标**（§6.2）。
16. **"该不该用 RL"不是决定 ICL 与技能注入的那个变量**。唯二能提高"用上下文定义任务"能力的方法都是 SFT（MetaICL 任务级元训练、符号调优）；决定 ICL 存亡的是**训练样本之间任务定义是否在变**。技能注入是**存放位置**问题，而单遍读出**无法执行流程**（§6.3）。
17. **任务无关的 RL 确有生命力，但不可导性与 RL 的收益面几乎不相交**。RL 泛化的是**二阶性质**（置信、校准、约束满足），凡以验证器为奖励处均被系统性套利；真正既不可导又无认证手段的只有"Agent 下游结果与决策→动作"，而那恰是 RL 实测收益为零之处。所以"目标不可导所以要用 RL"**不成立**（§6.4）。
18. **输出的形状比目标函数更值得改**。适当评分规则已到顶（标签已知时与 RLCD 式奖励同最优点、标注者分歧下可证明不能胜过交叉熵）。四种输出里三种形状是错的：布尔**缺第三个真值**（还原 P(U) 后软准确率 0.771→0.978）；选择的读出**是序数的不是概率的**（序数层误差 4.2 点、概率层 21.0 点）；序数被**系统性压缩**（40 数据集 × 9 模型，规模不能恢复）。数值不该用标量回归（区间决策树把 MAE 从 5.18% 降到 1.84%），算术必须外包（§6.5）。
19. **思维链要引入，但推理时不应该是 token 流**。训练时蒸馏最优（27B 在 JEVal 上与 Jev 持平、约 0.1 s）；层循环是唯一有深度外推证据的零 token 路线，但要求循环预训练骨干，**与我们的混合基座不兼容且无桥梁工作**；**读别人的链最被低估**（1,500 token 预算下 +4.1 pp、被截断题 +8.6 pp，省 71.3% 成本）。System 1 自己的展开形式是**问题图**，不是 token 流。硬界限是 Jev 做不出"LLM 只有写出中间步骤才能做出"的决策（一次前向可解 97.5%、其余 **74%**），而且**它不知道自己的界限**（§6.5）。
20. **按核心逻辑读这一章会得到一个额外结论**：未调优读出已达调优后准确率的 **76–97%**，调优增益随规模从 15.8 点缩到 **2.3 点**，"预训练提供表示，调优只调整怎么读"（[2610.15501](https://arxiv.org/abs/2610.15501)）。所以该问的不是"怎么把读出训得更准"，而是"**怎么让读出不丢掉表示里已有的语义**"——而针对这一点的现成手段只有渲染修补（+0.1511）与符号调优，**都没在决策模型上试过**（§2.1.7）。

### 3.6 终局尺寸：27B / 35B 这一档改变证据的读法

21. **终局目标取定为 Qwen 27B / 35B 这一档**，而这一档上的证据与小模型档**方向不同**。先分清架构：**27B 是稠密的，而 Qwen 没有稠密 35B——所有 35B 都是 `35B-A3B` 的 MoE（约 3B 激活）**；若终局落在 35B-A3B，则 §1.3 的三个结构假设之外还多出一项"逐 token 专家路由是否在隔离的问题分支间引入新耦合"，**本报告对此零命中**。而在 27B 上：决策微调增益已缩到 **2.3 点**（未调优读出达到调优后的 76–97%，"预训练提供表示，调优只调整怎么读"）；**新 schema 上增益约为零**（87.8–88.1 对未调优 89.1）；**让它推理仍显著优于读出**（96.9 对 89.1；数值类 schema 上读出每个规模都只有 56–66%、推理 98–100%）；该档最强的正面结果是**蒸馏**而非决策 SFT（Reasoning-to-Readout 自蒸馏让 27B 与 Jev 持平、约 0.1 s）。反方证据也要记住：**领域微调的小模型可以胜过通用的大模型**（SecJev-0.8B 比 Kev-9B 高 20.51 pp），所以"终局要大"需要独立理由。**合起来**：这一档上值得投入的不是"把读出训得更准"（只剩 2.3 点），而是"让读出不丢掉表示里已有的语义"与"把推理蒸进读出"；小尺寸阶梯的作用也随之从"终局的缩小版"变成**结构性改动的试验台**（§6.1.5）。

### 3.7 评测与自我复核

22. **"怎么评测"文献已给出答案，而现有论文的合规率很低**：14 项检查表中"同骨干标签对数概率基线"26 篇适用论文只有 5 篇合规、"选项名不变性测试"27 篇只有 1 篇、"带缓存与不带缓存两套延迟"20 篇只有 3 篇。**也就是说公开数字里"接口的功劳"与"模型的功劳"基本没被分开过**。按业务属性看，**业务人员可配置与可审计两格是零**；最大的缺口是业务目标本身——**每正确结果的端到端成本没有任何可复现口径**，而一篇自审计把自己"省 23.9%"订正为 **4.3%**（§7）。
23. **四个工作假设里三个"结论对、机制错"**。原因是提问者的判断来自部署观察，对**现象**可靠；机制归因需要控制实验，而文献恰在这几处缺控制实验。**遇分歧应保留现象、重做机制**（§8.1.1）。
24. **报告里有八个框架是我自己造的**，不是文献结论（七个泛化层次、五类可导性、三层幂等、五个 System1+System2 位置、决策重复度轴、问题图、十二条业务属性、D4 的 30 个子维度），其中后三者过拟合风险最高。正文里"按这个分类看 X 格是零"应读作"**按本报告这种分类看**"（§8.1.2）。
25. **达成一致不是检验通过**。七条对抗性攻击里，框架的**两处表述被推翻**（等价类自身是新增的不幂等源；"模型管语义、代码管记账"只在代码参数不拟合于模型候选时成立）、**三处必须加限定**（预先登记、系统层/模型层分开、功劳只在取定上）、**一处曾未决、现由设计选择裁决**（让它便宜的操作与毁掉规则敏感性的操作**是同一个**：可缓存独立编码约 5 倍便宜、规则敏感度 1.00 → 0.24，[2609.37832](https://arxiv.org/abs/2609.37832)；第八轮取定的顺序选了贵的、规则敏感的那一侧，残差是混合骨干上的递归压缩，§8.2.1 A4 后记二）、**一处是永久折扣**（四个承重点各只有一篇六周内的预印本支撑）。§8.2.4 列了五条会推翻框架的观测，其中三条所需的测量现在就能做（§8.2）。第六轮讨论之后 A1 被消解（等价类由问题诱导）、A4 升级为骨干特定版本（48/64 层递归层只传递与问题无关的摘要），见 §2.2.4 第 11–12 行。

- **范围**：以 TypeSafe 的 Jev / System One 为锚点，覆盖本体文档、第三方架构还原、独立评测与审计、开源复现（解码器路线为主），以及五个维度各自的上游学术文献。

## 5. 证据可信度与注意事项

- 绝大多数证据是 **arXiv 预印本**（未经同行评审），时间窗口极窄（发布后 6 周内）。多篇自述为"早期证据"。
- Jev 的训练细节（RLCD、数据、骨干）**未公开**；所有架构描述来自黑盒探针与开源复现的推断。
