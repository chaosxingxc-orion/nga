# 下一代 Agent 技术路线调研：Jev 类快思考模型与快/慢协同框架

> 调研报告 · 2026-10-27 · 仅分析与调研，不含训练方案
>
> 仓库目的：讨论下一代 Agent 的技术路线。核心论点有两条：
> 1. **Jev 类（System One）快思考模型**使"快/慢协同"的 Agent 框架成为可能，把 Agent 循环从"慢思考 + 执行反馈"改为"快思考 / 慢思考两种模式协同"。
> 2. 在我们自己训练 Jev 类模型之前，先按五个需求维度把近期（2026 年 9–10 月为主）的学术工作梳理清楚：**哪些工作解决了哪一类问题，哪些是我们识别出来但现有工作没有覆盖的盲区**。

## 3. 核心结论速览

1. **Jev 的价值在接口、成本、延迟与校准，而非准确率**。早期审计（28 篇论文）结论是"类型化读出本身未显示出独立于同类标签概率读出的准确率优势"（[2609.32160](https://arxiv.org/abs/2609.32160)）；现成聊天模型直接读 logits 已是 Jev 式决策模型（[2610.02076](https://arxiv.org/abs/2610.02076)），Gemma-4-31B 加一个按选项数拟合的温度即可在 Decision Index 排第 2（[Mapika/decider](https://github.com/Mapika/decider)）。
2. **架构已被还原并被 15 个以上开源配方复现**：共享状态前缀 + 隔离的问题分支 + 列表式概率读出（[Archer Hume](https://archerhume.com/posts/jevs-architecture-unmasked)）。0.6B–9B 的决策微调模型可用，**领域微调的小模型胜过通用的大模型**（SecJev-0.8B 比 Kev-9B 高 20.51 pp，[2610.03073](https://arxiv.org/abs/2610.03073)；AgentDecision-4B 在分布外任务 91.5% 对 Jev 82.0%，[2610.21412](https://arxiv.org/abs/2610.21412)）。
3. **D1 的真实状况**：模型"读得懂"示例与定义，但**标签名压倒定义**（AUC 93.8% → 23.2%，[2609.26758](https://arxiv.org/abs/2609.26758)；删除定义准确率不变，[2610.02586](https://arxiv.org/abs/2610.02586)）；1–12B 小模型在上下文中**无法翻转标签语义**（[2511.21038](https://arxiv.org/abs/2511.21038)）；同质示例让 0.8B–8B 模型准确率坍塌到 12% 以下（[2605.08295](https://arxiv.org/abs/2605.08295)）。没有任何论文直接测量"决策微调是否保留/破坏 ICL"。
4. **D2 的瓶颈不在"读"而在"做"**：策略修改被正确读出，但只在 22%–72% 的情况下被执行（[2610.18579](https://arxiv.org/abs/2610.18579)）；含算术/时间的对照对从难度 1 到 3 准确率 87.7% → 57.4%（[2610.28522](https://arxiv.org/abs/2610.28522)）；正确答案缺席时拒绝率只有 7%，加一个阈值可到 79%（[2609.39496](https://arxiv.org/abs/2609.39496)）；兜底选项让 Intern 从 97.9% 跌到 23.1%（[2610.19856](https://arxiv.org/abs/2610.19856)）。
5. **D3 已有可借鉴的原语雏形**：Noul / Choice / Score 三原语、扇出、逐层走分类树、复合打分、置信路由（TypeSafe 文档）；SemTree 的 Yes/No/Unknown 节点树可逐节点修复（[2610.13999](https://arxiv.org/abs/2610.13999)）；"概率感知、确定性裁决"的 true/false/unknown 准入与并集界（[2610.10978](https://arxiv.org/abs/2610.10978)）。但**把自然语言业务规则编译为可验证逻辑**的工作（Artic、P2T、SIRNA、Cedar 自动形式化）都面向生成式 LLM，尚无针对单遍决策模型的规则语言。
6. **D4 远不止四项**：本报告枚举了重复性、顺序/位置、选项集依赖（IIA）、问题形式、分解、措辞、标签/定义、序数、多正确项分配、拒绝/兜底、校准-判别-敏感度分离、先验偏移、语言/文化、教师偏差继承、数值/时间、状态长度与无关信息、记录 vs 观测、接口、决策→动作、对抗、风格偏置、跨模型/版本等共 **30** 个子维度（A 同输入稳定性 / B 选项表示依赖 / C 逻辑相干性 / D 不确定性语义 / E 输入内容敏感性 / F 接口与动作，上面列的是其中代表项），并给出每项的可量化定义与现有证据。
7. **D5 的关键发现是"更快的决策 ≠ 更好的 Agent"**：孤立问题最准的决策模型只解出 69.5% 的 Agent 任务，不拟合阈值就委托工具选择会让成功率降 19.0 点（[2610.21412](https://arxiv.org/abs/2610.21412)）；Jev 控制器让成本增加 19% 而通过率不变（73.0% 对 73.0%，[2610.24649](https://arxiv.org/abs/2610.24649)）；决策模型更信任"记录"而非"观测"（53%–100%，[2610.25947](https://arxiv.org/abs/2610.25947)）。有效的快/慢协同都依赖**按选择逐项拟合的置信阈值**、**自身轨迹上的训练数据**与**代码中的组合**。
8. **骨干约束**：Qwen3.5 / 3.8 是 Gated DeltaNet + 注意力的混合架构，循环层不认注意力掩码，树形掩码无法隔离兄弟分支；现有做法是每个问题单独一行（Kev）或前缀分叉（qwen-rlcd，推理快 8–19 倍，但穿过缓存的梯度尚未实现）。针对混合架构的"训练时分支隔离"文献为零命中。
9. **学习算法几乎没有"换算法"**：相对普通分类微调，现有方案改的是读出位置（复用输出层 / 字母 logit / 指针头）、目标函数里加一个适当评分项（CE + Brier）、以及数据构成（对比策展、自提问、Agent 自身轨迹）。可证实有效的是 LoRA（对秩不敏感）、数据构成、结构隔离与温度；软标签"可能无用"且无对照（[2610.17205](https://arxiv.org/abs/2610.17205)）；单遍模型上强化学习为负或无效（发布 RLCD 配方比交叉熵低 2.5–3.0 点，[2610.02486](https://arxiv.org/abs/2610.02486)；REINFORCE −10.2 F1，[2610.06744](https://arxiv.org/abs/2610.06744)；GRPO 无增益，[2610.21412](https://arxiv.org/abs/2610.21412)），正面证据都绑定推理链。基座几乎全是 Qwen3.5（混合）或 Qwen3（纯注意力，用于结构研究）+ Gemma 4 做大模型；Base / Instruct 无共识。训练数据多数公开（Kev、Tev1、Nimble、Open-Jev、OneJev、Eikos），StartLux 与 TypeSafe 不公开；中文决策数据只有一家，无业务规则类数据（12 章）。
10. **同一个词在不同论文里是不同定义**："决策模型"按接口、契约或用途定义；"置信度"是分布统计量、top-1 概率、学到的风险分数或两个不可合并的量；ECE 有 10/15 等宽、15 等质量、相对零假设等至少五种算法；"翻转率"有五种分母；"RLCD"至少四种含义；"弃权"是选项、概率带、分数或兜底动作。跨论文数字不可直接比较的根源在此；我们定义问题前至少要取定六个分歧点（13 章 §13.9）。
11. **"SFT 无法带来一般意义上的泛化"这一假设：强形式不成立，弱形式成立**。同任务族的新样本 / 新来源上决策 SFT 可靠迁移（Kev 新来源差距随规模从 17.9 点收敛到 1.4 点）；但新 schema 上 27B 的 SFT 增益约为零（88.1 对未调优 89.1，[2610.15501](https://arxiv.org/abs/2610.15501)），新符号操作（名字压倒定义、学会跟踪不等于服从、反事实监督只在合成规则上奏效）、先验偏移（同样的决策 SFT 在金融情感上 +10.0 或 −12.0，[2610.26325](https://arxiv.org/abs/2610.26325)）、校准迁移与推理深度四层没有任何正面证据。跨层移动结果的是基座规模、指令调优起点、监督分布与结构约束，不是监督目标（14 章）。小模型上的 SFT 增益主要是读出对齐，**不能外推到大模型**。
12. **"该不该用 RL"不是决定 ICL 与技能注入的那个变量**。文献里唯二能提高"用上下文定义任务"能力的方法都是 SFT——MetaICL 的任务级元训练与符号调优（后者还直接提升**翻转上下文标签**的能力，正对 D1 最严重的缺陷，[2305.08298](https://arxiv.org/abs/2305.08298)）；决定 ICL 存亡的是"训练样本之间任务定义是否在变"，任务固定则无论 CE 还是策略梯度都会把任务烧进权重。技能注入是**存放位置**问题：上下文技能 +16.6 pp 但 91.8% 的公开 SKILL.md 有缺陷（[2602.12670](https://arxiv.org/abs/2602.12670)、[2608.08453](https://arxiv.org/abs/2608.08453)），权重技能（超网络→LoRA）更省 token 且更强（[2606.06087](https://arxiv.org/abs/2606.06087)）；而单遍读出**无法执行流程**，只能让技能影响那一次读出。RL 的独立价值仅在"奖励依赖于被采样的中间对象"时成立（推理链、示例集编辑）；对纯读出，NDM 证明它与适当评分规则同最优点（[2610.25553](https://arxiv.org/abs/2610.25553)），实测增益很小或为负（15 章）。
13. **任务无关的 RL 确有生命力，但不可导性与 RL 的收益面几乎不相交**。存在性证明就是 Jev 自己（RLCD 训练却通用）：一个通用问题在十类对齐失败、44 个基准上零样本达到 AUROC 中位数 0.886 并胜过多数有监督基线（[2609.29429](https://arxiv.org/abs/2609.29429)）；RL 泛化的是**二阶性质**（置信、校准、约束满足），不是一阶任务知识，而且凡以验证器为奖励处均被系统性套利（[2610.19525](https://arxiv.org/abs/2610.19525)）。把业务期待按"为何抗拒梯度"分类后：校准已有最优点正确的可导代理；一致性类可导但被结构化构造碾压（零翻转按构造成立）；风险阈值类零梯度而文献共识是事后统计认证（[2610.34329](https://arxiv.org/abs/2610.34329)）；真正既不可导又无认证手段的只有"Agent 下游结果与决策→动作"，而那恰恰是 RL 实测收益为零之处（GRPO 无增益、控制器只涨成本）。因此"目标不可导所以要用 RL"在现有证据下不成立（16 章）。
14. **"把不幂等的生成式判断换成指标输出 + harness 的确定执行"这条命题，诊断部分成立、描述部分不成立**。它准确预言了哪一类部署会失败（决策权回到模型里的那一类），但六条反证推翻了它的前提与结语：宿主 Jev 本身就不幂等（相同重复调用下 510 个标签改 4 个、300 题上最多 1.33% 改变，四篇论文报告其非确定性，[2609.32160](https://arxiv.org/abs/2609.32160)），而一个普通解码器加原子标签 token 已经是"确定的一步解码"且对 Jev 准确率相当、中位更快（[2609.36115](https://arxiv.org/abs/2609.36115)）；格式保证属于**语法约束解码的既有谱系**，而硬 schema 把答案准确率从 19.7% 压到 11.0%、把"合法但答错"从 49.5% 抬到 88.9%（"错误是语义的，不是结构的"，[2605.26128](https://arxiv.org/abs/2605.26128)）；"指标"只能被读作**相对于那张选项表**的相对量——预先登记的 299,463 次调用里每一个被加入的选项都移动对数几率，系统性偏移是自身噪声的 **1.2–3 倍**，而消除它要付 8.7 点（[2610.16655](https://arxiv.org/abs/2610.16655)）；harness 也不是确定性保护区——查询计划的选择会改变结果且选择下推在自校准升级带下不是质量可靠的（[2610.08089](https://arxiv.org/abs/2610.08089)），139 个论文族里只有 4 个报告截止期达成率，排队一来所有延迟保证失效（[2610.06425](https://arxiv.org/abs/2610.06425)）；最后，能力不守恒：Jev 做不出"LLM 只有写出中间步骤才能做出"的决策，而且**它不知道自己的界限**（[2610.24929](https://arxiv.org/abs/2610.24929)）。可以守住的版本是：**它不消除非幂等，它把非幂等的表面收缩成可数、可定界、可定价的若干个字段**——文献里的精确动词是"**定位（localize）而非消除**"（[2610.33876](https://arxiv.org/abs/2610.33876)），而真正的奖品是一个**不依赖校准**的裁决翻转上界（"unknown 即拒绝"的构造，36,000 次调用无一格推翻，[2610.10978](https://arxiv.org/abs/2610.10978)）；代价是失败从显性变成隐性。**把幂等改写成"设计目的"也要单独检验，结论是必须重写**：按字面意思它已经达成（同请求 ICC 0.997，[2609.36399](https://arxiv.org/abs/2609.36399)；同文重跑翻转 0.17%，[2610.35826](https://arxiv.org/abs/2610.35826)）却什么也没买到（"一致的答案也会保留错误"，重复的错误占观察到错误的大部分，[2609.27678](https://arxiv.org/abs/2609.27678)），而且它可以不用模型买到（查表即严格幂等；类型化策略字段上一条确定性规则全对；不带模型的控制器解出 79%，[2610.24871](https://arxiv.org/abs/2610.24871)）；企业侧被强制的其实是同案同判 + 可复现记录 + 有界错误率 + 可申诉，而位级幂等既不充分（硬 schema 合法率 100% 但准确率 11.0%、"合法但答错" 88.9%）也不必要（评分卡靠单调、可取阈、可审计立足）。可检验的目的是一个**三元组**——等价类内同判 + 等价类外仍给得出决策 + 单价低一到两个数量级——翻译成模型侧要求是**单调可取阈的分数、原生 unknown、业务等价类内不变**，幂等本身住在**阈值与确定性契约**里（[2610.10978](https://arxiv.org/abs/2610.10978)）（17 章 §17.1、§17.1.6）。
15. **业务目标是单价，不是准确率；属性清单里只有两条可承诺**。被消除的是解码 + 往返 + 解析成本：rubric 评审贵 16–357 倍慢 5–350 倍（[2609.29769](https://arxiv.org/abs/2609.29769)）、审核约 0.000025 美元/次约 100 ms 且 AUROC 与 14 个前沿系统中 13 个不可分（[2610.33258](https://arxiv.org/abs/2610.33258)）、本地 2B 30.9 ms 零输出 token 对前沿 API 8,758 ms（[2609.23886](https://arxiv.org/abs/2609.23886)）。可承诺的只有"输出必在选项集内"与"一次前向答完整个请求"；校准、等价提法不变性、兜底、unknown、自知、概率自洽、可审计、风险预算八项都有独立审计测出的反例，其中最差的是兜底（答案缺席时正确拒绝率 7%，加阈值可到 79%，[2609.39496](https://arxiv.org/abs/2609.39496)）与自知（无相关信息时对显著选项给到 0.80，[2610.01006](https://arxiv.org/abs/2610.01006)）。支撑 System1+System2 有五个工程上不同的位置，前四格（入口闸、过程监控、证据/记忆面、慢模型输出读出器）有正面证据，第五格（闭环执行者）普遍失败（17 章）。
16. **输出的形状比目标函数更值得改**。适当评分规则已是共识且已到顶（标签已知时与 RLCD 式奖励同最优点、标注者分歧下可证明不能胜过交叉熵、加 Brier 项对准确率无效）。而四种输出里三种形状是错的：布尔缺第三个真值（还原 P(U) 后软准确率 0.771→0.978，[2609.35342](https://arxiv.org/abs/2609.35342)）；选择的读出**是序数的不是概率的**（序数层误差 4.2 点、概率层 21.0 点，[2610.07716](https://arxiv.org/abs/2610.07716)），非对称代价下用它的概率可能比用 top-1 更差（[2610.11392](https://arxiv.org/abs/2610.11392)）；序数被系统性压缩（40 数据集 9 模型，刻度变细更严重、规模不能恢复，[2609.38827](https://arxiv.org/abs/2609.38827)），而 Kev 的序数损失在发布模型里未启用。数值不该用标量回归：区间决策树把归一化 MAE 从 5.18% 降到 1.84%（[2609.28587](https://arxiv.org/abs/2609.28587)），而算术必须外包（答案缺席时拒绝率 7%）（18 章）。
17. **思维链要引入，但推理时不应该是 token 流**。四种用法里：训练时蒸馏最优（Reasoning-to-Readout 自蒸馏让 27B 在 JEVal 上与 Jev 持平、约 0.1 s，[2610.03935](https://arxiv.org/abs/2610.03935)）；层循环是唯一有深度外推证据的零 token 路线（SanSi 比同形状非循环高 13.5 点并把可解深度推到训练深度之外，[2610.07730](https://arxiv.org/abs/2610.07730)；LEV 2.6B 深度 1→4 从 63.2% 到 76.2%，[2610.20951](https://arxiv.org/abs/2610.20951)）但要求循环预训练骨干，与我们的混合基座不兼容且无桥梁工作；读别人的链最被低估（1,500 token 预算下比强制作答 +4.1 pp、被截断题 +8.6 pp，省 71.3% 成本，[2610.25768](https://arxiv.org/abs/2610.25768)）；自己生成链有效但把成本搬回生成式一侧，只配做置信门控的逃生通道。而 System 1 自己的"展开"形式是**问题图**——多问近乎免费、多生成按量计费：LAVOIR 一次前向同时返回决策与每个待问信息的期望增益，最多 0.5 个追问即比从不追问高 14.1 点（[2609.30706](https://arxiv.org/abs/2609.30706)）。硬界限是 Jev 做不出"LLM 只有写出中间步骤才能做出"的决策（一次前向可解的题 97.5%、其余 74%），而且**它不知道自己的界限**（[2610.24929](https://arxiv.org/abs/2610.24929)）（18 章）。
18. **"怎么评测"文献已给出答案，而现有论文对它的合规率很低**。一份 14 项检查表加一张最小报告卡已经存在，但"同骨干标签对数概率基线"26 篇适用论文只有 5 篇合规、"选项名不变性测试"27 篇只有 1 篇、"带缓存与不带缓存两套延迟"20 篇只有 3 篇（[2609.32160](https://arxiv.org/abs/2609.32160)）——也就是说公开数字里"接口的功劳"与"模型的功劳"基本没被分开过。按业务属性看覆盖面严重不均：准确率、校准、一致性、对抗有多个大规模基准，而兜底、unknown、自知、概率自洽、风险预算是单篇或两篇孤证，**业务人员可配置与可审计两格是零**。最大的缺口是业务目标本身——**每正确结果的端到端成本没有任何可复现口径**，而一篇自审计把自己"省 23.9%"的结论改成"省 4.3%"（[2610.02267](https://arxiv.org/abs/2610.02267)）（19 章）。
19. **复核：四个工作假设里三个"结论对、机制错"，而本报告有八个框架是自己造的**。H1（SFT 不泛化）结论对而机制不完整；H2（业务期待不可导）结论对而理由错；H4（幂等搬迁）诊断对而描述错；只有 H3（用 RL 保 ICL 与技能注入）方向不成立。这个模式有原因：提问者的判断来自部署观察，对**现象**可靠；机制归因需要控制实验，而文献恰好在这几处缺控制实验（没人测决策微调前后的 k-shot 曲线、没人把 Jev 的重复抖动与温度 0 的生成式基线并排测、没人在同一批数值决策上比较三条数值路线）。所以遇分歧应**保留现象、重做机制**。同时，七个泛化层次、五类可导性、三层幂等、五个 System1+System2 位置、"决策重复度"轴、"问题图 vs token 流"、十二条业务属性、D4 的 30 个子维度**都是本报告的构造而非文献结论**，其中后三者过拟合风险最高；正文里"按这个分类看 X 格是零"应读作"按本报告这种分类看"。我自己最该防的缺陷是确认偏差，且已有一次实例：17 章初稿六条反证里有四篇论文早已在本报告其他章节被引用，失败不在检索而在**写新章时没做反向检索**（20 章）。
20. **两条后续命题的检验：核心逻辑是"语义理解的泛化"（不是"变成代码"），以及"决策一致率是核心指标、对错第二顺位"**。前者成立，而且是用本报告自己的归谬成立的——"把决策权挪到代码"的无约束最优解同样是查表，所以措辞已改为"**模型负责语义，代码负责记账**"：把开放世界情形映射成带刻度的观测记录这一步没有任何代码写法。支持它的最强单条证据是**一个通用问题零样本跨十类对齐失败、44 个基准达到 AUROC 中位 0.886 并胜过多数有监督基线**（[2609.29429](https://arxiv.org/abs/2609.29429)）——规则引擎与查表都做不到。但这个口径下结论更难听：单遍类型化读出恰恰在语义层最弱（名字-定义对调 AUC 93.8%→23.2% 而类型错误率全程 0%、删除定义准确率不变、1–12B 少样本语义覆盖率为零、跨裁判迁移 67.70%→47.87%），而且**让它便宜的那个操作与毁掉规则敏感性的操作是同一个**（可缓存独立编码约 5 倍便宜、规则敏感度 1.00→0.24，[2609.37832](https://arxiv.org/abs/2609.37832)）。后者也成立，但理由应更强——**一致率是正确率可被承诺的前提**（阈值只在分数分布稳定时有效：样本内拟合目标 5% 而保留集最高 17%），且聚合准确率对我们关心的变化是盲的（换 8 种顺序准确率变化 <2 pp 而累计失败集 +27–29%）。两条命题都必须补上同一项：**无约束最优解分别是查表与常数分类器**——三次命题都点名"不变性"而留空"判别"，所以可用形式是"一致率为目标、正确率为声明的地板"，且必须先取定分母（字节级重跑口径 99.83% 对保答案对抗变体口径 53.7%，相差 46 个百分点；唯一有业务含义的"业务等价类"口径无人定义过）（17 章 §17.1.6–§17.1.8、20 章 §20.3）。

## 4. 证据可信度与注意事项

- 绝大多数证据是 **arXiv 预印本**（未经同行评审），且时间窗口极窄（发布后 6 周内）。多篇论文自述为"早期证据"，样本量和模型版本差异大。
- Jev 的训练细节（RLCD、数据、骨干）**未公开**；所有架构描述来自黑盒探针与开源复现的推断。
- 开源复现之间的基准（JevBench、Decision Index、DecisionPivot、System1-Arena、TypedBench 等）口径不同，跨论文的数字不可直接比较。
- 本报告**不做选型、不写训练方案**；10 章只给出问题定义、度量与开放问题，12 章只比较学习算法与数据可得性，13 章只比较各论文的定义，14–16 章只审查工作假设与选型问题的证据，17–19 章只审查业务目标、输出形状与评测覆盖面的证据，**20 章复核前面各章的工作假设与本报告自己的构造，并列出我自己的方法论缺陷**。
