## Commands and trust boundary

Run the generation's frozen controller with `verify` or `inspect`, supplying
`--config ABSOLUTE_CONFIG --sha256 INDEPENDENT_CONFIG_PIN`. `inspect --output
NEW_PATH` writes a presence-only WAIT/readiness report naming every missing
member dependency. The V5 preparation inspection names 139 prerequisites:
80 present and 59 missing. Both actual inspect and the unchanged partial qualifier
return WAIT/exit2. File presence is not producer authentication or qualification.
These counts are observations, not future invariants. The fixed CPU analysis
environment executes all three verification commands; exact argv and exit codes
are retained in V5 `INVOCATION.json`. Earlier V4 preparation and recheck counts
remain historical evidence, not the current readiness state.

`watch` also requires an independently supplied `--activation` and
`--activation-sha256`. The activation must bind the exact config/controller and
an actual independent Astra PASS plus parent receipt. Never create that receipt
from this document or from producer flags. After independent source/config review
and separate parent authorization, run detached with durable output, fixed process
identity and log redirection. The watcher writes heartbeat, digest, relaunch and
terminal markers, is resumable between inspections, and stops at
`READY_FOR_PINNED_CONSUMPTION`. It does not automatically qualify the campaign.

`consume` separately requires `--bundle-sha256`, `--adjudication-sha256` and
`--output NEW_PATH`. It binds every configured role/plan/checkpoint/report/output
and source reference, then calls the **unchanged frozen qualifier** using its
real read boundary and numerical implementation. It never obtains either trust
pin by hashing a producer's asserted approval. Complete consumption can be costly;
run it as a separately reviewed detached CPU job with durable heartbeat/log/exit,
not in the NPU queue critical path. This preparation has not run full consumption.

The complete bundle and independent adjudication do not exist yet. Per-member
descriptor paths in the config reserve the independent evidence packages; they
are not synthetic entries. The immutable partial bundle intentionally has no
completed entries and a JSON-null pending adjudication. The actual accepted
qualifier returns WAIT/exit2, naming missing members and independent adjudication.
